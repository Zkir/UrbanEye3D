# Tree Species Database

This report lists all tree species known to the UrbanEye3D plugin. This information is then used to select the most realistic 3D texture for rendering.

To avoid regressions, **please do not edit the CSV file manually.** Instead, update the OSM Wiki or adjust the processing scripts in the `misc` directory.
